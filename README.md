# Chandra Akash Kiran — Data Science Portfolio

Responsive one-page portfolio for Junior Data Scientist / Machine Learning / GenAI roles.

## Run locally
Open `index.html` in a browser, or use VS Code Live Server.

## Deploy on Vercel
1. Create a new GitHub repository.
2. Upload all files from this folder.
3. Import the repository into Vercel.
4. Use the default static-site settings and deploy.

## Before deploying
- `resume.pdf` is already included from the supplied resume.
- Verify your LinkedIn URL in `index.html`.
- Add GitHub URLs for the Fraud Detection and Zomato projects when ready.
- You can replace the generated project visual with screenshots later.
