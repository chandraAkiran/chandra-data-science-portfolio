## Featured Projects

### 1. Enterprise GPT — AI Knowledge Assistant

A full-stack enterprise knowledge assistant that uses **Retrieval-Augmented Generation (RAG)** to answer natural-language questions from uploaded PDF documents.

**Key Features**
- PDF ingestion, text extraction and chunking
- Gemini embeddings and ChromaDB vector storage
- Semantic retrieval and context-grounded LLM responses
- LangChain agents and multi-LLM support with Gemini and OpenAI
- Supabase Authentication, PostgreSQL and Storage
- Chat sessions, conversation history and document management
- Next.js frontend deployed on Vercel
- FastAPI backend deployed on Render

**Tech Stack:** Python, FastAPI, LangChain, Gemini, OpenAI, ChromaDB, Supabase, PostgreSQL, Next.js, RAG

**Live Application:** https://infosys-ai-knowledge-assistant.vercel.app  
**GitHub:** https://github.com/chandraAkiran/infosys-ai-knowledge-assistant

### 2. Credit Card Fraud Detection — Machine Learning Classification

An end-to-end machine learning project for identifying fraudulent credit-card transactions in a highly imbalanced dataset.

**Key Features**
- Data preprocessing and feature analysis
- Class-imbalance handling using SMOTE
- Logistic Regression and Random Forest model comparison
- Classification-threshold optimization
- Interactive Streamlit dashboard for transaction analysis, fraud-risk visualization and model evaluation

**Model Performance**
- ROC-AUC: **97.81%**
- F1-score: **82.54%**
- Precision: **94.55%**
- Recall: **73.24%**
- Optimized threshold: **0.68**

**Tech Stack:** Python, Pandas, scikit-learn, Random Forest, Logistic Regression, SMOTE, Streamlit

**Live Application:** https://credit-card-fraud-detection-cakiran.streamlit.app  
**GitHub:** https://github.com/chandraAkiran/Credit-Card-Fraud-Detection
